# Fonte do dossiê técnico

- `dossie.html` — documento (HTML + SVG inline), em A4.
- `img/` — telas da sessão de campo de 16/11/2026 (somente leitura).
- `render.js` — gera o PDF com Playwright/Chromium.

```bash
node render.js dossie.html ../Dossie_PD3-302.pdf
```

As fontes usadas são Inter e DejaVu Sans Mono; instale-as localmente para
reproduzir o mesmo layout.
